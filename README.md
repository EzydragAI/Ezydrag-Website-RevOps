# Ezydrag Marketing Automation

Editorial site for Ezydrag’s marketing-ops desks. Stack is Next.js, GSAP, Lenis, Zustand, TanStack Query, RHF + Zod. Motion language is referenced from `jesko-jets/` (loader line, slit-to-open hero, pinned method, horizontal product reel) — not its copy, fonts, or assets.

```bash
cd marketing-automation
npm install
npm run dev
```

Runs on port **3001**.
